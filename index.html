Ferret updates

Update feeds for Ferret, a tool to find and change values in your single-player games.

Linux

Install ferret.flatpakref (open it with your software centre), or run:

flatpak install --user https://petru101.github.io/ferret-updates/ferret.flatpakref

Later versions then arrive with your other Flatpak updates.

Windows

Download the installer from the latest release. Ferret updates itself after that.
